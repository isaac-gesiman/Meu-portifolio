Abrir 100 Abas com 1 Link

Um link, até 100 janelas lado a lado.

HTMLCSSJavaScript
Ler sobre o projetoVer no GitHub

Objetivo

Abrir o mesmo link em até 100 janelas ao mesmo tempo, lado a lado, para comparar, monitorar ou testar.

Sobre

Ferramenta de página única, feita com HTML, CSS e JavaScript puro, sem frameworks nem build. Funciona abrindo o index.html no navegador.

Como funciona

O usuário cola o link e escolhe a quantidade (de 1 a 100). O código valida e normaliza a URL, aceitando apenas http e https. Links do YouTube e do TikTok são convertidos automaticamente para a versão de incorporação. A página então monta a quantidade pedida de iframes em um grid responsivo, com 9, 6, 4 ou 2 colunas conforme a tela. Os iframes rodam em modo sandbox, com permissões controladas. Se o site bloquear a exibição em iframe, o botão “Abrir em abas” abre cada cópia numa aba separada. A interface tem modo escuro automático e funciona em celular.

Habilidades demonstradas

  • JavaScript puro com manipulação do DOM e validação de entrada.
  • CSS Grid responsivo, variáveis CSS, animações e dark mode.
  • Noções de segurança web (sandbox de iframes, noopener, filtro de protocolos).
  • Uso de embeds e capacidade de transformar uma necessidade pessoal em ferramenta.
