Lista Compartilhada

Várias pessoas, a mesma lista, sincronizada em tempo real.

JavaScriptFirebaseFirestoreTempo real
Ler sobre o projetoVer no GitHub

Objetivo

Permitir que várias pessoas criem e editem a mesma lista (de compras ou tarefas) com todos os dispositivos sincronizados em tempo real. O projeto resolve a limitação de listas guardadas só no navegador de um usuário.

Sobre

Projeto avaliativo A3 de Sistemas Distribuídos e Mobile na UnP, feito em grupo de três pessoas. O front-end é feito em HTML, CSS e JavaScript puro com módulos ES, usando o Firebase como backend (BaaS). O README é um relatório técnico completo, com arquitetura, modelo de dados, segurança e os problemas que a equipe enfrentou.

Como funciona

O usuário se cadastra ou entra com e-mail e senha ou com a conta Google, e cai no painel com suas listas. Cada lista é um documento no Cloud Firestore, com os itens e os e-mails de quem tem acesso guardados dentro dele.

  • Quando alguém altera algo, o onSnapshot atualiza a tela de todos os clientes conectados.
  • As regras de segurança do Firestore permitem que só o dono edite e que os e-mails compartilhados apenas leiam.
  • As páginas internas redirecionam para o login se não houver sessão.
  • O nome da lista é salvo com debounce de 600 ms, para não gravar a cada tecla.

Habilidades demonstradas

  • Integração com Firebase Authentication (e-mail/senha e OAuth com Google) e Firestore.
  • Comunicação em tempo real com listeners reativos.
  • Modelagem de dados NoSQL e regras de segurança no servidor.
  • Proteção de rotas.
  • JavaScript moderno com módulos, debounce e tratamento de condições de corrida.
  • CSS responsivo com variáveis (design tokens).
  • Documentação técnica e trabalho em equipe.
