Projeto Biblioteca Municipal

Empréstimos, devoluções e multas de uma biblioteca pública.

Objetivo

Digitalizar a gestão de uma biblioteca pública, controlando livros, leitores, empréstimos e devoluções, com acesso separado para bibliotecários e leitores.

Sobre

Sistema web feito com Ruby on Rails 8 e PostgreSQL, publicado na plataforma Railway. É o projeto mais completo da sua conta, com regras de negócio, e-mails automáticos, testes e integração contínua.

Como funciona

O bibliotecário cadastra usuários, outros bibliotecários, livros e categorias, e registra empréstimos e devoluções. O leitor tem uma área própria para ver seus empréstimos, a data de devolução e o status, e para renovar.

As senhas usam has_secure_password (bcrypt). Quem é cadastrado recebe uma senha provisória por e-mail e precisa criar a definitiva no primeiro acesso. Cada leitor também tem uma senha de empréstimo de 8 dígitos, usada para confirmar cada retirada. O sistema aplica várias regras:

  • Verifica a idade mínima de cada livro.
  • Marca o livro como indisponível enquanto está emprestado.
  • Define 20 dias de prazo.
  • Permite uma única renovação, e só para empréstimos que não estão em atraso.
  • Calcula multa de R$ 1,00 por dia de atraso.
  • Um índice único no banco impede dois empréstimos em aberto do mesmo livro. A devolução usa transação para manter os dados consistentes.
  • Os e-mails (senha provisória, senha de empréstimo e recuperação de senha) são enviados pela API do Brevo.

Habilidades demonstradas

  • Desenvolvimento full stack com Ruby on Rails (MVC, rotas, models, controllers, views).
  • Modelagem relacional em PostgreSQL, com migrations, chaves estrangeiras e índices.
  • Autenticação com dois perfis e fluxo de primeiro acesso.
  • Regras de negócio e validações.
  • Integração com API externa de e-mail.
  • Segurança com Brakeman, bundler-audit e variáveis de ambiente.
  • Testes automatizados e CI com GitHub Actions (RuboCop, testes e testes de sistema).
  • Dependabot, Docker e deploy em nuvem.
